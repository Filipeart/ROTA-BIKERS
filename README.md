ROTA BIKERS 🏍️

Sistema de Gerenciamento Logístico

Sobre o projeto

O ROTA BIKERS é um sistema web desenvolvido como projeto acadêmico para a disciplina de Fundamentos de Programação para Internet. Seu objetivo é facilitar o gerenciamento logístico de uma empresa de distribuição de produtos para motociclistas.

Objetivo

Organizar em um único sistema os cadastros de produtos, endereços, transportadores e fretes, facilitando o controle e a consulta das informações.

Público-alvo

Empresas de distribuição de mercadorias, especialmente do segmento de motocicletas, e funcionários responsáveis pela logística e pelo controle de entregas.

Funcionalidades

Cadastro e consulta de produtos.

Cadastro e consulta de endereços.

Cadastro e consulta de transportadores.

Registro e consulta de fretes.

Associação de vários produtos a um mesmo frete.

Relatórios de fretes por data com exportação em CSV.

Tecnologias utilizadas

PHP: processamento das informações.

HTML5: estrutura das páginas.

CSS3: aparência visual.

JavaScript: interações nos formulários.

MySQL: banco de dados.

XAMPP: ambiente de execução local.

Git e GitHub: controle de versão e armazenamento do projeto.

Figma: prototipação das telas.

Banco de dados

O banco rota_bikers possui cinco tabelas: produtos, enderecos, transportadores, fretes e frete_produtos.

Como executar

Instale e abra o XAMPP.

Inicie Apache e MySQL.

Coloque a pasta do projeto em htdocs.

Configure o banco de dados rota_bikers.

Acesse pelo navegador:

http://localhost/rota-bikers/
